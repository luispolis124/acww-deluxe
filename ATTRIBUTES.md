# Project Attributes & Scope - Animal Crossing Wild World Deluxe

This document outlines the core attributes, technical scope, and structural boundaries of the **Animal Crossing Wild World Deluxe** project.

## 📌 Project Attributes
* **Project Name:** Animal Crossing Wild World Deluxe (`acww-deluxe`)
* **Target Platform:** Nintendo DS (NDS) / Compatible Emulators & Flashcarts
* **Base Game:** Animal Crossing: Wild World (US/EU Retail Versions)
* **Distribution Format:** Binary Delta Patches (`.xdelta`) and open modding resources
* **Primary Focus:** Text script expansion, localized strings customization, event tweaking, and engine modification via binary/text hacking

## 🔧 Scope & Technical Boundaries
* **Text Archives (.bmg):** Modification and translation of core dialogue files (including villager homes, introduction/ending sequences, question frameworks, and event strings).
* **Binary Modifications:** Integration of codebase improvements inspired by open-source community repositories (such as `acww-hax`).
* **Compliance & Copyright:** Purely a modification framework. Contains zero copyrighted game binaries or ROM images. All changes are distributed strictly as delta patches.
