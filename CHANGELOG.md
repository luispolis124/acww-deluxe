# Changelog
All notable changes to **Animal Crossing Wild World Deluxe** will be documented in this file.
The format is based on Keep a Changelog,
and this project adheres to semantic versioning.
## [Unreleased] - In Development
### Added
 * Initial project structure and repository setup.
 * Integration framework using acww-hax for advanced code modifications.
 * Support for generating and applying .xdelta patches.
### Changed
 * Translation and text string updates (ongoing).
 * Asset optimizations using community tools like NitroPaint.
## [1.0.0-alpha] - 2026-06-08
### Added
 * First public alpha release of the mod (acww-deluxe.xdelta).
 * Initial set of text edits and custom item tweaks.
 * Basic compatibility with clean US/EU ROMs via XDelta patches.
