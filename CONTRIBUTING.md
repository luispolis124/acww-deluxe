# Contributing to ACWW Deluxe

Thank you for your interest in contributing to **Animal Crossing Wild World Deluxe**! Whether you are reporting a bug, suggesting a new feature, or submitting a patch update, your help is appreciated.

Please follow these guidelines when contributing:

## 🚫 Important Rule: No ROMs
* **NEVER** upload, link, or commit copyrighted ROM files (`.nds`) or proprietary game assets to this repository. 
* Pull requests containing raw ROM files will be closed immediately.
* Always distribute changes as patches (`.ips`, `.ups`, `.xdelta`) or scripts.

## 🐛 Reporting Bugs
* Use the **Issues** tab to report bugs or graphical glitches.
* Provide clear steps to reproduce the issue, along with screenshots or emulators used (e.g., MelonDS, DeSmuME).

## 💡 Suggesting Features
* Open an issue to discuss new features or gameplay changes inspired by *Animal Crossing Deluxe* or *City Folk*.

## 🔄 Submitting Patches
1. Fork the repository.
2. Create your feature branch (`git checkout -b feature/my-new-feature`).
3. Commit your changes (`git commit -m 'Add some feature'`).
4. Push to the branch (`git push origin feature/my-new-feature`).
