# Credits & Acknowledgments - Animal Crossing Wild World Deluxe

This file lists the creators, developers, inspirations, and open-source foundations behind the **Animal Crossing Wild World Deluxe** project.

## 🚀 Project Lead & Development
* **Luis Felipe Barbosa da Silva** (Lead Developer) - Project direction, text scripting, BMG editing, database restructuring, and overall custom mod implementation.

## 💡 Inspirations & Community Projects
This project draws immense inspiration from past and ongoing custom mod endeavors in the *Animal Crossing* community:
* **Animal Crossing Deluxe** by **Cuyler** - Inspiring modern enhancements and visual expansions.
* **City Folk** by **Aurum** - Influencing interface styling, village immersion, and feature integration.

## 🛠️ Technical Foundations & Tools
Special thanks to the developers and maintainers of the low-level hacking tools and repositories that made this project possible:
* **TheGag96** - Creator of the **acww-hax** repository, providing vital technical foundations, documentation, and game code modifications for NDS architecture.
* **UniPatcher & DeltaPatcher** - Essential patching utilities allowing players to apply modifications cleanly on both mobile and desktop platforms.
* **Blockbench & BMG Editors** - Used throughout the asset modification and text localization pipeline.
