# acww-deluxe

Official repository for **Animal Crossing Wild World Deluxe**. Contains only patches (IPS/XDelta/UPS) and modding tools. No ROMs are included.

---

## 📌 About the Project
**Animal Crossing Wild World Deluxe** is a custom mod project designed to enhance and expand the original *Animal Crossing: Wild World* experience (inspired by community projects like *Animal Crossing Deluxe* and *City Folk*). 

> ⚠️ **IMPORTANT COPYRIGHT NOTICE:** This repository **does not** contain any ROM files. You must legally acquire your own clean ROM of *Animal Crossing: Wild World* (Nintendo DS) to apply these patches.

---

## 🛠️ How to Apply the Patch

To play the mod, you will need:
1. A clean ROM of *Animal Crossing: Wild World* (US/EU version).
2. A patching tool (such as **Delta Patcher**, **Floating IPS (Flips)**, or **xdelta UI** depending on the patch format provided).

### Step-by-Step Guide:
1. Download the latest patch file (`.xdelta`, `.ips`, or `.ups`) from the [Releases](../../releases) section.
2. Download a patching utility (e.g., **Delta Patcher** for xdelta files).
3. Open your patching tool:
   * **Original file / ROM:** Select your clean *Animal Crossing: Wild World* NDS ROM.
   * **Patch:** Select the downloaded mod patch file from this repository.
   * **Apply Patch:** Click the apply button to generate your modified ROM.
4. Run the patched ROM on your Nintendo DS flashcard (like R4) or an emulator (like MelonDS or DeSmuME).
