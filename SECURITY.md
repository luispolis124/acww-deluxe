# Security Policy
## Supported Versions
Since this project deals exclusively with game patches (.ips, .ups, .xdelta) and modding utilities for *Animal Crossing: Wild World*, security updates are provided for the latest release branch only.

| Version | Supported |
| :--- | :--- |
| Latest | :white_check_mark: |
| Older | :x: |

## Reporting a Vulnerability
If you discover any security issues related to the repository scripts, tools, or links provided, please report them responsibly:
 * **Do not** open public GitHub issues for sensitive security matters or potential exploit vectors.
 * Instead, please contact the repository maintainer directly or utilize GitHub's private vulnerability reporting feature if available on this repository.
