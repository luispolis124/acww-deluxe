# Support
Getting stuck or need help with **Animal Crossing Wild World Deluxe**? Here is how you can find assistance.
## 🐛 Reporting Issues & Bugs
If you encounter a bug, a broken patch, or unexpected behavior while using the mod, please follow these steps:
 1. **Check existing issues:** Look at the Issues tab to see if your problem has already been reported.
 2. **Create a new issue:** If it's a new issue, open a New Issue.
 3. **Provide details:** Please include:
   * The version of the mod patch you are using.
   * Which emulator or hardware (e.g., melonDS, DeSmuME, R4 flashcard) you are running the game on.
   * Clear steps to reproduce the bug or a description of what went wrong.
## 💬 Questions and Discussions
For general questions, feature requests, or brainstorming ideas about the mod:
 * Feel free to open a discussion or comment on existing threads if available.
 * Remember to keep all communications respectful and in line with our community guidelines.
## 🛠️ Technical Limitations & Disclaimer
 * Please note that this repository **does not provide ROMs**. Requests for clean or modified ROM files will be closed immediately.
 * Ensure you are applying the patch to a verified, clean US/EU ROM of *Animal Crossing: Wild World* to avoid patching failures and unexpected desyncs.
